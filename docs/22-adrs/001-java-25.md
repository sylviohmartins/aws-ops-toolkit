# ADR 001 — Java 25 sem preview

Status: aceito para o skeleton; homologação corporativa pendente. Data: 2026-09-18.

## Context

O toolkit é executado localmente e deve priorizar Java 25, legibilidade e diagnóstico sob pressão. Novas regras não podem depender de opções experimentais para corrigir produção.

## Decision

Compilar com `release=25`, executar com distribuição/patch Java 25 homologados e bloquear preview no build. Usar records, interfaces pequenas e APIs estáveis. ScopedValue é opção para correlação imutável; manter contexto explícito nos contratos e rebind ao criar tasks. Structured Concurrency fica fora da baseline, pois segue preview no Java 25. [ScopedValue API](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/lang/ScopedValue.html), [Structured Concurrency](https://docs.oracle.com/en/java/javase/25/core/structured-concurrency.html).

## Alternatives

Java 21 teria maior histórico corporativo, mas não atende à prioridade definida sem exceção. Versões intermediárias/mais novas não justificam mudança automática. Preview oferece APIs interessantes, mas adiciona instabilidade de compilação e evolução desnecessária neste produto.

## Consequences

IDE, Maven, CI e execução precisam usar a mesma linha. Distribuição, licença, atualização de segurança e suporte são VALIDAR NO AMBIENTE. Não pressupor que todo scanner/plugin suporta bytecode 25; comprovar build e análise. Mudança de Java exige novo ensaio de memória, concorrência e shutdown. Detalhes em [JVM](../24-java-jvm.md) e [arquitetura](../02-architecture.md).
